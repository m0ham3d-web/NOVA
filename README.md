# NOVA — Premium Fashion

**Quietly iconic.** A modern minimalist fashion e-commerce experience designed to showcase clothing collections through an elegant and responsive interface.

## 🌐 Project Overview

NOVA is a front-end fashion store concept focused on simplicity, visual elegance, and a smooth shopping experience.

The project features a modern storefront where users can explore products, view product details, manage their shopping cart, and go through a checkout interface.

## ✨ Features

- 🛍️ Modern fashion storefront
- 👕 Product collections and categories
- 🔎 Product browsing and filtering
- 🧥 Product details with size and color options
- 🛒 Interactive shopping cart
- 💳 Checkout interface
- 🌙 Dark and Light mode
- 📱 Responsive design for mobile and desktop
- 🎨 Minimalist premium visual identity
- ✨ Smooth transitions and interactive elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Unsplash Images

## 🚀 Getting Started

You can run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/m0ham3d-web/NOVA.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.
